# 万蔵の大冒険 — 不思議な洞窟

ブラウザだけで遊べる、ターン制のダンジョンRPGです。
一歩動くと敵も動く。部屋と通路は入るたびに形が変わります。

スクエアエニックス作品ではありません。オリジナルの行商人「万蔵」の話です。

## 遊び方

`index.html` をブラウザで開いてください。

- 移動・攻撃: 矢印キー / テンキー / クリック
- 拾う: G または自分のマスをクリック
- 道具: I または Enter
- 階段: >
- 待つ: スペース
- 周囲の罠を探す: S
- 休む: R

地下8階の黄金のつぼを持って地上へ戻ればクリアです。
倒れると持ち物を失い、お金は半分になります。倉庫の品は守られます。
